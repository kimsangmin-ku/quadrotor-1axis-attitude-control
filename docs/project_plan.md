# 개인프로젝트 I 계획서
## 1축 테스트벤치 기반 쿼드로터 자세 안정화 제어기 개발·검증

작성일: 2026-09-14 | 작성자: 김상민 | 기간: 2026-09-15 ~ 2026-12-04 (12주)

---

## 1. 프로젝트 한 줄 정의

F450 쿼드로터의 한 축(roll)만 회전하도록 고정하는 시소형 테스트 지그를 직접 설계·제작하고, 개인 소유 MCU로 IMU 기반 자세 추정과 PID 제어기를 구현해 수평 유지 성능을 정량적으로 시험·튜닝·검증한다.

## 2. 왜 이 주제인가 (지원 직무와의 연결)

| 결과물 층 | 산출물 | 앞세울 회사·직무 |
|---|---|---|
| 1층 설계 | CATIA 3D 모델, 2D 도면, BOM, 설계 근거서, 지그 강성 손계산 | KAI·한화에어로·LIG 기계/구조 설계, 현대차 차량시스템 설계 |
| 2층 제어 | 자세 추정 코드, PID 제어 코드, 게인별 스텝응답 표·그래프 | 현대차 차량제어 SW, LG전자 로봇, 방산 유도제어·항공전자 |
| 3층 검증 | 1축 동역학 모델(Python/MATLAB), 시뮬레이션 vs 실측 비교 | 현대차 SDV, 방산 디지털 엔지니어링·시험평가 |

프로젝트는 하나, 자소서 서사는 세 개. 회사마다 바뀌는 건 프로젝트가 아니라 강조하는 층이다.

## 3. 전제와 제약

- 보유 부품 없음 (Mbed LPC1768은 수업용 대여 보드이므로 개인 프로젝트에는 사용하지 않음)
- 예산 30~80만 원
- 작업 시간은 평일만, 주당 약 6~8시간 가정
- 실제 비행 없음 (장소·자격증 문제) → 벤치 시험으로 전 과정 대체
- 진동해석 제외, 3D프린팅은 온라인 출력 대행
- 수업(항공전자모빌리티종합설계)과의 구분: 수업은 "시중 드론 보드 교체 후 동작", 개인 프로젝트는 "제어기 한 개를 실물에서 정량 시험·튜닝·검증"

## 4. MCU 선정 (핵심 결정)

**추천: STM32 Nucleo-F446RE (또는 F401RE)** — 약 2~3만 원

- 수업에서 쓰는 Mbed 생태계와 동일해 수업에서 배운 코드·PlatformIO 환경이 그대로 이식됨 (학습 비용 최소)
- 개인 소유이므로 프로젝트 소유권이 명확하고 졸업 후에도 보유
- STM32는 현대차·LG·방산 임베디드 직무에서 실제로 가장 많이 쓰는 계열이라 이력서에 쓸 때 가장 유리
- 대안: Arduino Nano (1만 원, 가장 쉬움, 어필도는 낮음) / ESP32 (1만 원, 무선 로깅 편리, 항공·차량 쪽 어필은 STM32보다 약함)

| 리스크 | 대응 |
|---|---|
| 부품 배송 지연 (해외 직구 시 2~3주) | 국내 재고 우선 구매, 1주차에 즉시 발주 |
