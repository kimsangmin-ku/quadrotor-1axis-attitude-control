# quadrotor-1axis-attitude-control

F450 쿼드로터의 한 축만 움직이게 지그에 고정하고, 직접 만든 제어기로 수평을 잡아보는 프로젝트.

## 왜 하죠?

이번 2학기에 듣는 [항공우주종합설계와 센서 및 계측공학] 이 두 과목에서 배우는 지식을 결합하여 실제 제어기를 만들어보고 비교적 간단한 구동 실험을 통해 실전 감각을 확보하려고

## 쓰는 것들

- 보드: STM32 Nucleo-F446RE
- IMU: MPU-6050
- 모터/ESC: 2212 1000KV × 2 (예비 1), 30A ESC × 2, 1045 프로펠러
- 지그: 알루미늄 프로파일 + 3D프린팅 (CATIA로 설계)
- 분석: Python
